# ZeroGravitation 🚀

A fast-paced space survivor roguelite inspired by Vampire Survivors.  
Fight endless waves of alien enemies, upgrade your ship, and survive the chaos of deep space.

## Features

- 🚀 Automatic combat gameplay
- 👾 Endless enemy waves
- ⚡ Random upgrades and powerups
- 🌌 Multiple space environments
- 💥 Unique weapons and abilities
- 🎮 Simple controls, intense action
- ☄️ Survive as long as possible

## Gameplay

Control a lone spaceship trapped in hostile sectors of space.  
Destroy enemy fleets, collect energy crystals, level up, and create overpowered builds to survive the swarm.

Every run is different thanks to randomized upgrades and enemy patterns.

## Controls

| Action | Key |
|--------|-----|
| Move | WASD / Arrow Keys |
| Pause | ESC |
